# Stage 10 implementation plan

1. Read each working blend in Blender and preserve the original file, bone matrices, action curves and mesh object identities. Use separate Stage 10 copies as the rollback boundary.
2. Replace local mesh data on the rigid components. Keep origin, parent and action contracts. Add details as children of existing moving pieces. Use a single sculpted scarf shell with a facial opening and a tapered shoulder drape.
3. Use the existing action sampler and facial render helpers to produce solo and paired previews. Sample every existing action and check scene attachment, grounding, materials and facial restoration.
4. Compare new 640 x 360 images against Stage 9, measure Blender runtime and sampled process memory, and document compatibility boundaries. Keep Workbench and the existing garden.
